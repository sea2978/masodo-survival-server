마소도 Cloudflare - GitHub 자동배포 (CMD 불필요)

[1] GitHub 저장소 만들기
1. https://github.com 로그인
2. 오른쪽 위 + → New repository
3. Repository name: masodo-survival-server
4. Public 또는 Private 선택
5. Add a README file은 체크하지 않아도 됨
6. Create repository

[2] 이 ZIP의 내용 업로드
1. 이 ZIP을 압축 해제
2. GitHub 저장소 화면에서 Add file → Upload files
3. 압축 푼 폴더 안의 '내용물 전체'를 업로드 영역으로 드래그
   - src 폴더
   - public 폴더
   - package.json
   - wrangler.jsonc
   - README.md
   - .gitignore
   - DEPLOY_STEPS_KO.txt
4. 아래 Commit changes 클릭

중요: ZIP 파일 자체만 GitHub에 올리면 안 됨. 반드시 압축을 풀어서 내용물을 저장소 루트에 올릴 것.

[3] Cloudflare와 GitHub 연결
1. https://dash.cloudflare.com 로그인
2. Workers & Pages
3. Create application
4. Import a repository 옆 Get started
5. GitHub 계정 연결/승인
6. 방금 만든 masodo-survival-server 저장소 선택
7. Worker 이름은 반드시 masodo-survival-server 로 설정
   (wrangler.jsonc의 name과 같아야 함)
8. Root directory: 저장소 루트(/)
9. Build command: 비워도 됨
10. Deploy command: npx wrangler deploy
11. Production branch: main
12. Save and Deploy

[4] 배포 완료 후
배포 성공 시 https://masodo-survival-server.<계정>.workers.dev 같은 주소가 생김.
그 주소를 브라우저에서 열면 멀티플레이 Phase 1 테스트 화면이 뜸.

[5] 다음부터 수정하기
GitHub 저장소에서 파일을 수정하거나 새 파일을 업로드하고 Commit하면 Cloudflare가 자동으로 다시 빌드/배포함.
따라서 싸지방 PC에서도 CMD 없이 브라우저만으로 업데이트 가능.
