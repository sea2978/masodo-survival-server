# 운영 시간·사용량 차단·방 채팅 (정식 출시 1.0.0)

한국 시간 매일 17:30부터 24:00 직전까지 온라인 서버를 개방합니다. 자정에는 진행 중 경기와 로비 연결을 종료하며, 10분/5분/1분 전 안내를 보냅니다. 오프라인과 튜토리얼에는 제한을 적용하지 않습니다.

## 배포 전 필수 설정

Cloudflare → Workers & Pages → 해당 Worker → Settings → Variables and Secrets:

- `CF_ACCOUNT_ID`: 해당 Cloudflare 계정 ID (Text).
- `CF_ANALYTICS_TOKEN`: 해당 계정의 Analytics Read 권한이 있는 API 토큰 (**Secret**). HTML이나 GitHub 파일에 넣지 않습니다.
- `OPERATING_HOURS_ENABLED=true`, `QUOTA_GUARD_ENABLED=true`는 wrangler.jsonc에 포함되어 있습니다.

Cron Trigger는 매분 사용량을 조회합니다. 처음 배포한 뒤 첫 정상 조회 전에는 안내와 함께 접속을 거절합니다. 자격 증명이 없거나 최근 10분 동안 정상 조회가 없으면 보호 차단됩니다. 정식 운영 주소는 https://masodo-survival-server.cheonbung.workers.dev/ 입니다. 토큰 설정이 없으면 배포 후에도 보호 차단 상태가 유지됩니다.

## 80% 기준과 한계

현재 감시 대상은 **계정 전체 Workers 요청 수 및 Durable Objects 원시 invocation 요청 수**입니다. UTC 00:00(한국 09:00)부터 각 항목이 80,000 이상이면 해당 UTC 날짜 동안 닫힙니다. 다음 날 정상 조회와 운영 시간 조건을 모두 만족해야 다시 열립니다. 표본 값이 내려가도 같은 날 차단은 해제하지 않습니다.

DO WebSocket 메시지는 청구 시 20:1 할인이 적용되지만 HTTP/RPC/알람에는 적용되지 않으므로, 원시 invocation 전체를 20으로 나누지 않습니다. 따라서 이 보호 장치는 실제 청구 사용량 80%보다 **일찍 닫힐 수 있습니다**. Analytics 집계 및 1분 조회 간격 때문에 정확한 실시간 80% 상한을 보장하지 않습니다. 실행 시간(GB-s)·저장소 한도는 이번 감시 대상이 아닙니다. 실제 계정 GraphQL 응답과 권한은 배포 환경에서 검증해야 합니다.

매 게임 메시지마다 원격 사용량을 조회하지 않고 방별 15초 상태 캐시를 사용합니다. 자정 경계는 캐시와 관계없이 검사합니다. 차단 시 접속자에게 사유를 전송하고 소켓·게임 알람을 종료하고 방 목록에서 제거합니다. 이후 상태 확인 API/안내 요청과 모니터링 자체의 사용량은 남습니다.

## 방 채팅

방 목록 → 현재 방에 채팅창이 표시됩니다. 서버가 참가자 이름과 시간을 붙이고, 입장한 사람만 전송·기록 조회가 가능합니다. 메시지는 1~300자, 1초 간격으로 전송합니다. HTML 문자열은 실행하지 않고 텍스트로 표시합니다.

서버 저장소에 50개 단위로 기록하며, 입장·재접속 시 최신 50개와 ‘이전 대화 더 보기’를 제공합니다. 방이 유지되는 동안 이전 페이지를 모두 조회할 수 있습니다. 방 삭제/마지막 참가자의 명시적 퇴장/빈 방 만료 시 기존 방 삭제 정책에 따라 함께 삭제됩니다. 서로 다른 방의 기록은 공유하지 않습니다.

## 검증

`npm test`는 기존 회귀 검사와 `test:operations-chat`을 포함합니다. 운영 시간 경계, 79,999/80,000 요청, 누락·오래된 사용량, 자정/사용량 종료, 자동 재접속 중단, 저장소 재생성 후 115개 기록 복원·페이지·동시 전송·방 분리 등을 검사합니다. 클라이언트 시작 검사는 실제 HTML 코드의 채팅 렌더링·한글 전송·텍스트 처리·종료 안내를 DOM 모형에서 실행합니다.

전체 npm test 및 Wrangler 배포 dry-run 빌드는 통과했습니다. 실제 로컬 Worker 실행은 환경의 uv_interface_addresses 오류로 실패하여 실제 WebSocket 통합 검증은 미완료입니다. 실제 Cloudflare 배포 및 사용량 API 검증은 별도입니다. 브라우저 실행 파일 다운로드 실패로 실제 모바일 화면의 시각 검수는 미완료입니다.
